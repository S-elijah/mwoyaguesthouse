# Mwoya Guest House 

This repository contains the source code for the official web application of **Mwoya Guest House**, located in Kakuuto - Kyotera, Uganda. 

Live Website: [mwoyaguesthouse.netlify.app](https://mwoyaguesthouse.netlify.app/)

##  About the Project
Mwoya Guest House offers clean, comfortable accommodation for travelers alongside *The Oak & Ember* bar. The website serves as a digital storefront to showcase rooms, the bar, gallery spaces, and contact/booking details.

##  Built With
- **Frontend:** HTML5, CSS3, JavaScript
